# Agriport 🚜

Agriport is a full-stack Agricultural Transport Management System that connects farmers with transport drivers for crop transportation.

## Features

### Farmer Module

* Farmer Registration & Login
* Book Transport Vehicles
* Select Available Drivers
* Track Vehicle Location
* View Order History
* Profile Management
* Help & Support

### Driver Module

* Driver Registration & Login
* View Assigned Trips
* Accept Transport Requests
* Update Current Location
* Complete Trips
* Profile Management

### Admin Module

* Dashboard Overview
* Farmers Count
* Drivers Count
* Bookings Count
* Completed Trips Count

## Technology Stack
